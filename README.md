# peekstack

Peek color stack values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/peekstack/

## Install / run

```bash
git clone https://github.com/theworker02/peekstack.git
cd peekstack
node src/cli.js
node --test
```
